# AND SO this is a very quick template for an addon to cool mod Penumbra Phantasm by SGUDest1ny!
- To get started you might want to *clone* this project to your own device, git handles that ;3
- Then after making sure this abomination can launch on your device via task > runClient, you SHOULD rename all instances of `GastersDarkWorldMachine` and `gdwm` to whatever mod name and mod id you want (!)
In order to achieve that you can use nifty `f2` or `shift+f2`
- With this you *"SHOULD"* be done! Do whatever and make your epic dark worlds ;3
